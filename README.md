# Dumb baseline exercise
  
## Installation & Setup
 
### 1. Install uv
 
**macOS / Linux:**
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```
 
**Windows (PowerShell):**
```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.sh | iex"
```
 
### 2. Activate project

Run bash command:
```bash
uv sync
```
Run powershell command:
```powershell
.venv\Scripts\activate
```
